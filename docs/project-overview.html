SQL_TEST_01 · Project Overview

What This Project Is

SQL_TEST_01 is a five-build agent portfolio project demonstrating SQL, Docker, and Python agent-engineering skills for a placement track.

The project runs on a Dockerized PostgreSQL 17 and SQL Server 2019 lab.

Build 1 is a hand-rolled tool-use loop, no agent framework, that answers plain-English questions about a database by writing its own SQL behind a read-only role.

Build 2 built a real raw-to-clean data pipeline from a genuine equipment-checkout export, split into a raw staging schema and a typed clean schema.

Build 2.5 gave the agent a writable scratch workspace with its own narrowly-scoped role, so it can persist computed results instead of only reading.

Build 3 added semantic search with pgvector over the data, so the agent can answer thematic questions with no exact keyword match.

Build 3.5 extends that same semantic search to the project's own documentation, so the agent can answer questions about its own build history.

Build 4, planned, adds tool-call observability and an eval harness. Build 5, planned, adds live deployment with CI.

The build sequence is deliberately chosen to compound the same spine rather than sprawl into disconnected demos.
